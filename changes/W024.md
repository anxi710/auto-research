# W024: Use Markdown as the standard research delivery

Status: adopted.
Date: 2026-10-28.
Scope: the requested format rule in this local candidate.
Baseline: `b0306c681bf93a250294f3e800634d9dcfd0f9b6`.
Standalone workflow version: `0.1.11-markdown.1`.
Integrated workflow version: `0.1.11-synthesis.3`.
Report skill version: `0.1.1-markdown.1`.

## Request and boundary

The user requested Markdown delivery while retaining the research-report writing guidance.
LaTeX and PDF remain available when explicitly requested.
This format change does not adopt the broader W019 trial or establish new writing-quality evidence.
The separate synthesis PR #4 remained an open draft when this branch started.
The standalone format commit `6dd3566` kept those six commits separate.
The user then authorized adding this format change to PR #4 without rewriting its existing commits.

The old delivery guide allowed LaTeX when it suited a formal report.
That wording allowed the assistant to choose it without a format request.
The existing record checker did not require a PDF.
This change narrows the instructions and tests the existing format-independent checker.

## Changed behavior

Markdown is the standard researcher view, including substantial formal reports.
The summary, full account, argument, source support, readable evidence links, and agent evidence view remain required at the appropriate scale.
Existing scientific versions and human decisions keep their authority.
Missing TeX sources, PDF output, compilation, or PDF layout inspection do not make a Markdown delivery incomplete.

An explicit format request selects the optional rendering path.
The template guide explains the existing Paper, Note, and Book choices, dependencies, build helper, and return to Markdown.
Missing dependencies remain visible and require authorization before installation.
Requested PDF builds and page inspection remain unrun when the environment cannot perform them.
No configuration system, compiler installer, or new delivery validator was added.
The vendor sources, licenses, build helper, and prior evidence remain unchanged.
