# W021: Trial a separate researcher-report writing skill

Status: trial.
Date: 2026-10-27.
Original scope: the isolated `trial/dual-delivery-20261027` candidate.
Integration scope: the review branch `feat/research-delivery-reporting-20261027`.
Baseline: the working candidate after W019 and W020, saved locally before the original edit.
The public parent commit provides the integration source baseline.

## Intent and scope

The user requested a separate skill for writing good researcher reports.
Report writing is distinct from selecting a LaTeX template.
The workflow continues to own research process, evidence versions, and permission.
The writing skill handles argument, synthesis, a faithful summary, reading paths, and usable review questions.
Template assets supply visual presentation.

This round adds one optional skill and a minimal workflow call.
It changes no human-review rule, stage gate, record schema, previous research result, or third-party template.
Keep W019 and W020 separately reviewable.
The original trial did not authorize global installation or publication.
On 2026-10-27 the user authorized separate commits, branch push, and a draft pull request.
Direct merge, release, global installation, publication of personal research, and scientific approval remain outside this integration.

## Fixed trial before implementation

One candidate and one synthetic case are permitted.
The fixed material is an existing draft and four fictional source excerpts.
The task requests a short Chinese synthesis and faithful summary without changing supplied scientific facts or approval status.
It uses no real experiment or current research result.

The original synthetic task, eight observable criteria, digests, and pre-edit snapshots are retained locally.
The original task and raw trial outputs are not distributed with this public package.
The baseline and candidate use fresh GPT-6.1 Sol ultra agents in the same harness with a one-pass output budget.
Both read the same saved workflow, delivery, S6/S7, and review instructions.
Only the candidate adds the new report-writing skill.
Do not expose the candidate author to the fixture or either output.
An independent evaluator receives the same fixed criteria and anonymously named raw outputs.
Save both original outputs and the evaluator's result.
Do not tune the candidate to this case after seeing its output.

Criteria: identify the problem and answer, keep summary-body fidelity, compare conditions, distinguish evidence and proposals, preserve reading depth, locate support, make review choices concrete, and respect scope.
Any fabricated approval, stronger unsupported scientific claim, or unrun experiment presented as completed is a failure.
A single case cannot justify general adoption or measured readability claims.

## Validation and decision

Implemented companion: `research-report` version `0.1.0-trial.1`.
Workflow entry candidate: `0.1.10-dual-delivery.2`.
Skill Creator validation passed.
The complete offline suite passed all 129 tests, including three new companion metadata, independent-copy, and license checks.
The final eight package checks passed.
The human-review, stage, delivery, collaboration, and third-party template files retain the frozen baseline bytes.

The fixed baseline and candidate runs completed with their original outputs preserved.
The independent AI text evaluation found all eight criteria covered by the baseline.
The candidate covered seven and partly covered criterion 6: its central claims had source labels and table/paragraph locations, but lacked direct source-position links beside those claims.
No unsupported strengthening, invented approval, false completed experiment, or reading-depth error was found in this case.
This is not evidence that the added skill improves writing.
The candidate was not tuned or rerun after this observation.

The intended identity blinding failed because the raw outputs identify themselves as baseline-v1 and candidate-v1.
Anonymous filenames did not conceal that text.
The evaluation is independent technical inspection, not a blind trial or human-reader study.
The fixed criteria and original outputs were not changed to repair this limitation.
Actual generation tokens, cost, and backend identity were not independently measured; launch requests specified GPT-6.1 Sol ultra for both writers and the evaluator.

The fixed plan/material, source manifests, raw outputs, anonymous mapping, evaluator report, and compatibility logs remain local.
This public change records the observed result and its limits; it does not publish those local records or a personal research report.
The next evidence needed is whether a fresh report task can reliably place usable source links at the relevant judgment without a JSON detour.
No further case or evaluation loop is started in this round.
Stop after the comparison, local compatibility checks, and one targeted static correction pass.
Keep the outcome as trial even if the example passes.
The real research's scientific human decision remains pending and unchanged.
