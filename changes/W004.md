# W004: Make research preferences optional and local

Status: adopted.
Date: 2026-10-23.
Baseline: `ea6979a`, package version `0.1.0`.
Candidate: package version `0.1.1` in this toolkit.
Related records: [W002 L1](W002.md#l1-use-one-primary-library-and-keep-selected-notes-in-git) and [W003](W003.md).

## Intent and authority

The user wants a shared toolkit that each user can customize.
The user also authorized their habits as an optional example inside the skill.
Their approval of Zotero and selected Git notes applies to their personal defaults.
It does not select that setup for every user.

The authorized change separates shared instructions, local preferences, and optional examples.
Current requests and explicit project conventions take priority over local defaults.
Existing research records, library contents, sibling repositories, and installed skill copies stay outside the edit scope.
L2, L3, and L4 remain pending user validation.

## Candidate and fixed evaluation

The shared package reads optional preferences without selecting a personal library.
It continues from supplied evidence when no preferences file exists.
Paths in preferences start from the directory that contains that file.

Allowed files cover startup routing, preference guidance, templates, the optional example, documentation, history, tests, and the Git ignore rule.
The user's actual choices belong in the ignored workspace file `RESEARCH.local.md`.
The shared Zotero example contains no personal repository path.

The [acceptance conditions](../tests/preferences.md) were written before the generic candidate edits.
They cover local choices, higher-priority choices, and work without preferences.
They also cover source identity, reading depth, existing records, and private file exclusion.

Try one candidate with at most 15 local tool calls per fresh test session.
Keep networking, experiments, and external library operations unavailable.
Stop after the focused cases and package inspection.
This is a user-requested capability change, not a claim of measured research improvement.

## Evidence and decision

Focused behavior results: local preferences, project precedence, and no-preferences reading passed in fresh sessions.
The [evidence file](../tests/evidence/W004.json) preserves inputs, outputs, hashes, and reports.
Package inspection: metadata, local links, private-file exclusion, and plain-English inspection passed.
Independent review: the inspectable conditions passed.
Adoption decision: apply optional preferences and the optional example in this package's version `0.1.1`.

The final bulk route also names explicit project conventions after review found an omission.
That wording correction received focused inspection.
Current-request precedence over an explicit project convention remains unrun.

The old W003 results do not count as tests of this candidate.
Record any unrun precedence or portability cases in the final result.
Live account access and native discovery in other harnesses remain outside these tests.
