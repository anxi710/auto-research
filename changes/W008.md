## Required behavior

An interrupted write must leave the final file absent or unchanged.
A save must not overwrite a frozen record or its remaining temporary file.
A failed answer save must preserve the pending request and query count.
Resuming must not repeat an uncertain question.
Complete responses saved before a state update must remain usable.
Damaged legacy responses must remain available for inspection.
Recovery messages must identify the answer file and notebook.
