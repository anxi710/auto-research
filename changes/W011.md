Status: adopted.

## Fixed acceptance conditions

Existing offline behavior tests must continue to pass.
New checks must detect broken local paths, heading anchors, root entry imports, skill metadata, version badges, and license copies.
Temporary examples must demonstrate both valid inputs and rejected faults.
Code examples and external URLs must remain outside link inspection.
Personal root files and the source report must remain outside package inspection.
The checks must preserve inspected file bytes and use only the Python standard library.
CI must run the same local test command on pushes and pull requests.
CI must use read-only repository permissions and cover Python 3.9 and 3.14 on Ubuntu.
No test step requires research accounts or third-party packages.

## Candidate and comparison

The [package tests](../tests/test_package.py) keep the small helpers and their tests together.
They support this repository's inline Markdown links, heading forms, and simple frontmatter.
They do not implement full Markdown or YAML parsing.
The [CI workflow](../.github/workflows/tests.yml) reuses the existing offline test command.
It pins [checkout v7.0.1](https://github.com/actions/checkout/commit/3d3c42e5aac5ba805825da76410c181273ba90b1) and [setup-python v7.1.0](https://github.com/actions/setup-python/commit/6d4fd22b20465ccc0f7354476588e8df7c9ca0e0) to official release commits.
GitHub documents the workflow fields in its [syntax reference](https://docs.github.com/en/actions/reference/workflows-and-actions/workflow-syntax).
Runner setup can download the actions and Python.
The actual tests use local synthetic files and no research services.

Fixed fault comparisons use a missing local target and a mismatched version badge image.
Each fault runs through the same full test command in separate baseline and candidate copies.
An independent reviewer prepares additional cases before reading the implementation.
Those cases cover composed Markdown, a missing duplicate anchor, a broken linked badge, a wrong entry target, and root containment.
Local YAML inspection checks triggers, permissions, action pins, the version matrix, and the test command.

The baseline passed 61 tests on Python 3.9.25 and 3.14.8.
The candidate passed 69 tests on both versions, including eight new package tests.
uv 0.13.5 created both isolated environments in temporary directories.
Neither environment contained installed third-party packages.
Python 3.9 required a runtime download during preparation.

The baseline missed both injected faults.
The candidate detected both without changing inspected files.
The independent comparison passed all ten expected outcomes across five paired cases.
The valid composition passed in both versions.
The candidate detected all four independent faults that the baseline missed.
All existing behavior tests passed in those runs.
The independent review found no remaining issue within the declared scope.

The workflow YAML parsed successfully with an already installed parser used only for this inspection.
Its triggers, permissions, action pins, matrix, timeout, and test command matched the declared configuration.
