The editable report uses ElegantPaper 0.12 and the repository's researcher-paper adapter.
It adapts the Paper example to English with lang=en.
The class and adapter are loaded from their existing repository paths.
No vendor files are copied into this output directory.

From any directory, run:
bash /tmp/auto-research-markdown-smoke-latex/build.sh

The local script uses the documented XeLaTeX setup with -no-shell-escape.
It selects the local report by its absolute path and writes all build output here.
Two passes resolve internal references.
This report uses direct local evidence links and has no bibliography or figure sources.
It therefore needs no BibTeX pass or bibliography file.
ElegantPaper still requires the BibLaTeX package.

The repository build helper was also tested:
cd /workspace/auto-research-markdown-delivery
./templates/latex/build.sh paper /tmp/auto-research-markdown-smoke-latex
It stopped before compilation because ctex.sty was missing.
That helper targets the original Chinese example and requires CJK packages.
The English report does not use CJK fonts or ctex.
