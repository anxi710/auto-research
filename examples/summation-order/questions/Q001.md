# Q001: Does input order change the observed error?

This question concerns a synthetic practice exercise.
A floating-point value is a finite binary approximation.
The practical decision is how to record a small computation and its limits for independent review.

The planned hypothesis is that input order changes the plain loop's result on the cancellation case.
The alternative is that all declared orderings produce the same result under the recorded environment.
The exact control tests whether both methods can produce the same error.
Neither a tie nor evidence against the hypothesis invalidates an accurately executed and reported task.

The [source notes](../LITERATURE.md) explain the known method and input semantics.
The [fixed plan](../experiments/E001.md) specifies the inputs, methods, and exact error measure.
This is an exercise using known numerical behavior, not a claim of novelty.
It does not study runtime speed, statistical significance, real data, or multi-agent quality.
