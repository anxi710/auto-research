# Evidence decision aid

Use this aid when a task compares gates, subsets, or uncertainty.

Read each gate before comparing candidates.
Apply each gate to the unit named in the policy.
Separate missing evidence from evidence that fails a gate.
Do not assume that a summary statistic transfers to a different load or population.
Before combining summary statistics, state the needed assumptions.
Compare all required gates in one final decision.
Choose a next measurement that resolves the remaining decision.
Keep an inherited wrong claim beside its corrected scope.
